# Python Menu-Driven Calculator

## About the Project
This is a beginner-friendly calculator developed using Python. It performs mathematical operations on multiple integers entered by the user.

## Features
- Addition of multiple numbers
- Subtraction of multiple numbers
- Multiplication of multiple numbers
- Calculation of average
- Reuse existing numbers
- Enter a new list of numbers
- Add or delete numbers from the current list

## Concepts Used
- Python lists
- User-defined functions
- Loops (`while` and `for`)
- Conditional statements (`if`, `elif`, `else`)
- List comprehension
- Built-in functions (`sum`, `len`)
- User input and type conversion

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the Python file:

```bash
python calculator.py
```
